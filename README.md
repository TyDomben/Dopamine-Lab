# HOOKED 🧠

> A brutally self-aware meta-game about dopamine reward systems

**HOOKED** is an experimental game where players architect psychological manipulation circuits while the game openly shows them how they're being manipulated. It's both the laboratory and the experiment - you're simultaneously the researcher, the subject, and the manipulator.

## 🎮 Core Concept

Build neural reward circuits using drag-and-drop nodes. Each connection generates "dopamine units" used to unlock more sophisticated psychological manipulation components. **The game explicitly labels every trick it uses while using those same tricks.**

### The Hook

- Start naive, thinking you're just playing a game
- Become the architect of your own manipulation
- Enter awareness mode - see every trick being used on you
- Realize knowledge doesn't equal immunity
- Keep playing anyway

## 🧩 Game Mechanics

### Circuit Builder (Primary Gameplay)

Drag-and-drop node system with progressively unlocking psychological exploitation mechanics:

**TIER 1 - Basic Nodes:**
- 🔌 Input Node - generates base resources
- ⚡ Amplifier - multiplies output
- 🎯 Reward Center - converts to dopamine
- 🔄 Feedback Loop - creates circular dependencies

**TIER 2 - Psychological Manipulation:**
- ⏱️ Anticipation Delay - adds tension before rewards (+30% satisfaction)
- 🎰 Variable Reward - slot machine mechanics
- 🎲 Near-Miss Generator - shows "97% legendary!" (but RNG was decided instantly)
- ⚡ Combo Multiplier - escalating rewards for speed

**TIER 3 - Advanced Exploitation:**
- 🔥 Streak Counter - loss aversion mechanics
- 💤 Idle Processor - rewards for leaving/returning
- 📊 Progress Bar - never truly empty (starts at 15% after filling)
- ⏰ FOMO Timer - artificial scarcity and urgency

**TIER 4 - Meta Awareness:**
- 📈 Analytics Module - shows real-time manipulation metrics
- 👁️ Awareness Override - toggle manipulation visibility
- 🤖 Efficiency Optimizer - AI suggests optimal addiction circuits

### Resource Economy

- **Dopamine Units** ⚡ - Primary currency, always increasing
- **Neural Connections** 🔗 - Spent to wire nodes
- **Insight Points** 👁️ - Earned through self-awareness
- **Prestige Tokens** ⭐ - Permanent cross-run upgrades

### Game Phases

1. **NAIVE** (0-3 min) - "Click to generate dopamine"
2. **ARCHITECT** (3-10 min) - Unlock psychological exploits
3. **AWARE** (10-30 min) - See the manipulation in real-time
4. **DESIGNER** (Prestige+) - You're the dealer now

## 🔊 Dopamine Architecture

### Sound System (Web Audio API)

Every sound is carefully crafted to maximize dopamine response:

- **Click confirmation**: 800Hz, 50ms - instant gratification
- **Resource gain**: Ascending C4→E4→G4 major triad
- **Combo sounds**: Pitch increases per level (523Hz to 1319Hz+)
- **Reward tiers**: From single dings to full fanfares with bass drops
- **Ambient layer**: 60Hz hum that scales with production rate
- **Anticipation pattern**: Rising pitch (200Hz → 800Hz) over 1.5s

### Visual Feedback

- **Number display**: Animated counters (never instant)
- **Color coding**: White → Cyan (1K+) → Purple (1M+) → Gold (1B+)
- **Progress bars**: Rubber-band speed (fast start, slow near completion)
- **Particle systems**: Bursts on rewards, capped at 50 particles
- **Screen shake**: On mega rewards (+1001)
- **Node pulsing**: Glowing when charged and ready

## 🎨 Design Philosophy

### The Three Pillars

1. **Immediate Gratification**
   - First click gives visible reward
   - Numbers always moving upward
   - First unlock within 5 seconds

2. **Never Wait**
   - Always something to do
   - Multiple parallel progression paths
   - Background processes during "idle"

3. **Juice Everything**
   - Every action has sound + visual feedback
   - Smooth 60fps animations
   - Satisfying particle effects

### The Meta Hook

The ultimate irony: **Awareness doesn't create immunity.**

Players see every trick, understand every manipulation, read the honest tooltips... and keep playing anyway. The game demonstrates that:

- Knowing you're being manipulated ≠ Being able to stop
- Intelligence doesn't protect against dopamine circuits
- Self-awareness can become part of the addiction

## 🧠 Psychology References

This game implements real psychological principles:

- **Variable Ratio Reinforcement** (Skinner)
- **Near-Miss Effect** (Reid, 1986)
- **Loss Aversion** (Kahneman & Tversky)
- **Sunk Cost Fallacy**
- **Goal Gradient Effect** (Hull, 1932)
- **Flow State Manipulation** (Csikszentmihalyi)
- **Scarcity Bias** (Cialdini)
